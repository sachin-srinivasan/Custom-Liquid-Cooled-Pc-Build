# Custom Liquid-Cooled PC Build

A custom-built liquid-cooled workstation assembled from the ground up, featuring high-performance AMD and NVIDIA hardware, BIOS configuration, cable management, and full system setup including Windows installation and tuning.

## Overview
This project involved planning, assembling, and configuring a custom desktop system designed for high-performance operation, thermal efficiency, and long-term stability. I completed the full build process myself, including hardware installation, system wiring, BIOS setup, storage configuration, and operating system installation.

## System Specifications
- **CPU:** AMD Ryzen 7 7800X3D
- **GPU:** NVIDIA GeForce RTX 4070 SUPER 12GB
- **Power Supply:** Thermaltake 1000W 80+ Gold
- **Memory:** 32GB 6400 MHz RAM
- **Storage:** Samsung 2TB 9100 PRO PCIe 5.0 M.2 SSD with heatsink

## Work Completed
- Selected and integrated all core hardware components
- Installed and configured the motherboard, CPU, GPU, RAM, PSU, and storage
- Built and routed a liquid-cooling setup
- Managed internal cabling for airflow, reliability, and clean system layout
- Configured BIOS settings for stable system operation
- Installed and configured Windows
- Verified system functionality, thermal behavior, and general stability after assembly
